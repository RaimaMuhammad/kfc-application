CART CRUD
Cart route: http://localhost:8080/api/cart

Before testing the cart, use a real user_id and product_id.
Check the user ID in MySQL:

SELECT id, firstname, lastname, email FROM users;

Check product IDs in MySQL:

SELECT id, title FROM products;


TESTING CART POST — RAW / JSON

POST
http://localhost:8080/api/cart

{
  "user_id": 1,
  "product_id": 1,
  "quantity": 2
}

Replace user_id and product_id with IDs that exist in your database.


TESTING CART GET — READ ONE USER'S CART

GET
http://localhost:8080/api/cart?user_id=1

Replace 1 with the real user ID.


TESTING CART PUT — CHANGE QUANTITY — RAW / JSON

PUT
http://localhost:8080/api/cart/USER_ID/PRODUCT_ID

{
  "quantity": 5
}

Replace USER_ID and PRODUCT_ID with the same IDs used in the cart POST.


TESTING CART DELETE — REMOVE PRODUCT FROM CART

DELETE
http://localhost:8080/api/cart/USER_ID/PRODUCT_ID

Replace USER_ID and PRODUCT_ID with the same IDs used in the cart POST.

DELETING THE TEST USER

There is no user DELETE API route currently. Find the test user's ID in MySQL:

SELECT id, firstname, lastname, email
FROM users
WHERE firstname = 'Benedicto'
  AND lastname = 'Kiwanuka';

Delete that user's cart rows first, then the user. Replace USER_ID with the ID returned above:

DELETE FROM cart WHERE user_id = USER_ID;
DELETE FROM users WHERE id = USER_ID;
